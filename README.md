# SatuLaman — Jasa Landing Page UMKM & Bisnis Kecil

SatuLaman is a modern, lightweight, and conversion-optimized landing page designed specifically for Indonesian MSMEs (UMKM). It serves as a digital storefront that simplifies the customer journey, routing them directly from social media to a unified catalog, and finally to a direct WhatsApp checkout. 

This repository contains the front-end source code for the SatuLaman service page and its integrated interactive demos (e.g., Toko Beras Pak Kadi).

## 🚀 Key Features

- **Mobile-First & Responsive:** Optimized for smartphone screens, reflecting the browsing habits of local MSME customers.
- **Conversion Focused:** Strategic placement of "Konsultasi via WhatsApp" CTAs, including a sticky mobile action bar.
- **Interactive Demos:** Built-in modal components to showcase real-world MSME case studies (e.g., Toko Beras Pak Kadi) with live product catalogs and dynamic WhatsApp order generation.
- **Modern UI/UX:** Clean, spacious, minimal aesthetics using a modern card system, strong visual hierarchy, and accessible typography (Plus Jakarta Sans).
- **Reusable Components:** Modular architecture for Pricing Cards, FAQ Accordions, Feature Showcases, and CTA buttons.
- **Performance Optimized:** Fast loading, semantic HTML, and SEO-friendly metadata.

## 🛠️ Tech Stack

- **Framework:** React / Next.js
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Animation:** Framer Motion (Minimal, clean transitions)
