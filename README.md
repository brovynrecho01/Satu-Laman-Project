# 🚀 SatuLaman — Digital Sales Page System untuk UMKM

SatuLaman Starter adalah sistem halaman jualan digital (*digital sales presence*) terintegrasi yang dirancang khusus untuk UMKM dan bisnis lokal. Proyek ini dibangun untuk menyelesaikan masalah konversi trafik media sosial (Instagram/TikTok) yang sering bocor akibat ketiadaan katalog produk yang terstruktur dan alur pemesanan yang tidak jelas. 

SatuLaman menyederhanakan *customer journey* dengan formula: **Attract (Sosmed) ➔ Inform (SatuLaman Page) ➔ Convert (WhatsApp).**

---

## 🎯 Core Value Proposition
SatuLaman membantu bisnis kecil membuat calon pelanggan **lebih mudah menemukan, memahami, dan menghubungi** mereka melalui:
- **Mobile-First Catalog:** Katalog produk/layanan dengan harga transparan yang dirancang optimal untuk layar *smartphone*.
- **Direct WhatsApp Checkout:** Integrasi *1-click CTA* yang membawa pesanan pelanggan beserta format order langsung ke chat WhatsApp penjual.
- **WhatsApp Sales Kit:** Sistem *follow-up* dan manajemen komplain untuk mempermudah *closing* di WhatsApp.
- **Frictionless Onboarding:** Memanfaatkan *Business Intake Form* sehingga pemilik UMKM terima beres tanpa harus pusing memikirkan domain, hosting, dan integrasi teknis.

---

## 💻 Tech Stack & Programming Language

Proyek ini dibangun menggunakan pendekatan **Rapid AI-Assisted Development** untuk mencapai iterasi UI/UX yang cepat dan performa tinggi pada fase *Market Validation Sprint*.

*   **Programming Language:** TypeScript, JavaScript, HTML5
*   **Frontend Framework:** React.js 
*   **Styling:** Tailwind CSS (Modern Utility-First CSS)
*   **Icons & Assets:** Lucide React / SVG Icons
*   **Development Tools:** Google AI Studio / AI Coding Agents 

**Struktur Komponen Utama:**
- `AxionHero.tsx` – Halaman muka penawaran.
- `ValuePropSection.tsx` – Visualisasi alur konversi.
- `PricingSectionNew.tsx` – Modul penawaran program *Beta Sprint*.
- `FloatingWhatsAppButton.tsx` – *Sticky FAB* dengan indikator status *live* untuk akses konsultasi cepat.
- `DemoModal.tsx` – Fitur simulasi langsung (contoh: Toko Beras Pak Kadi).
